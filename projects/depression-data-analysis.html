Depression Data Analysis

Une étude de données qui transforme un jeu de données médical et socio-économique en informations compréhensibles et en prédictions évaluées.

Voir le dépôt GitHub ↗Me contacter

Le projet, en termes simples

L’objectif est de comprendre quelles informations décrivent le mieux une situation de santé et d’utiliser ces informations pour estimer si une personne présente une condition médicale chronique. Le modèle aide à repérer des tendances dans les données ; il ne remplace pas un diagnostic médical et ne prouve pas qu’un facteur est la cause d’un autre.

La démarche

  • Explorer les variables personnelles, sociales et liées au mode de vie.
  • Préparer les données pour qu’elles puissent être utilisées par les algorithmes.
  • Entraîner et comparer des modèles de classification.
  • Évaluer les résultats avec des métriques adaptées, notamment l’AUC-ROC.
  • Interpréter les variables importantes avec prudence.

Ce que le projet montre

Ce travail met en pratique toute la chaîne d’une analyse de données : passer d’un fichier brut à une question mesurable, construire une prédiction, vérifier sa qualité et présenter ses limites. Les notebooks Code.ipynb et depression-classification.ipynb sont disponibles dans le dépôt.
